# Contributing

Thanks for your interest!

## Reporting issues

Open a GitHub issue with:
- Board revision (silkscreen version, e.g. V1.0)
- What you observed vs. what you expected
- Scope captures, photos or logs where relevant

Errata confirmed on real hardware are tracked in [CHANGELOG.md](CHANGELOG.md).

## Pull requests

- Design changes: edit the EasyEDA Pro project in `hardware/easyeda/` and include a short
  description of *why*. Regenerate the schematic PDF, Gerbers and BOM only for tagged releases.
- Keep one logical change per PR.
- By contributing you agree your contribution is licensed under CERN-OHL-S v2 (hardware)
  or CC BY-SA 4.0 (documentation), the same as the rest of the project.
